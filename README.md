## 项目定位

**这是一个：**

- ✅ 全市场历史行情数据的本地采集与 SQLite 缓存工具
- ✅ 技术指标计算引擎（MACD(3,6,3)、KDJ(9,3,3)、均线、量能统计，参数口径统一可查）
- ✅ 基于明确量化规则的形态匹配度打分系统（规则完全透明，见下文）
- ✅ 可视化研究看板（候选池、指标明细、K线与指标联动图、行业分布）
- ✅ 历史回测与事后统计工具（分档绩效、累计收益、回撤与盈亏比，严格规避未来函数）
- ✅ 结构化研究简报生成器（九节学术格式排版 + 在线预览 + PDF 导出，结论可复现）
- ✅ 量化研究学习与工程实践的教学样本（测试覆盖、模块化、文档化）

**这不是一个：**

- ❌ 选股软件 / 操作指引生成器
- ❌ 策略优选或参数调优工具（回测仅是对**历史样本的事后统计**，不用于挑选参数、不宣称任何有效性）
- ❌ 自动交易或半自动交易工具（不对接任何券商接口，无任何下单能力）
- ❌ 付费服务、策略售卖、社群引流工具
- ❌ 云服务（**仅限本地运行，请勿将本服务部署到公网或对外提供服务**）

## 功能特性

- **打分体系 v1.1**：总分 100 三大模块——核心形态匹配（50）+ 筹码与基本面（20）+ 行业与板块（30）；热点行业名单可编辑（`config/hot_industries.json`），规则详见 [打分规则](#打分规则v11总分-100三大模块)
- **申万一级行业分类**：行业主源为申万一级行业成分（31 个行业，东财/新浪行业板块依次补缺），独立「代码-名称-行业-板块」对照表，行业与板块字段无空值
- **全市场扫描**：一次扫描覆盖沪市主板 / 深市主板 / 创业板 / 科创板全部股票（自动剔除北交所、ST/*ST/退市整理、停牌、次新）
- **指标口径统一**：MACD(3,6,3)、KDJ(9,3,3)（通达信 SMA 递推口径）、前复权价格，与常见行情软件一致
- **增量数据缓存**：收盘后扫描时当日 K 线由行情快照直接补全，无需逐股拉取历史；自动检测除权除息导致的前复权漂移并全量重拉；支持离线重算（`scripts/rescore_v11.py`，不重新拉取K线）
- **筹码集中度（可选）**：可选抓取筹码分布数据参与打分；接口缺失时对应项自动计 0 分，流程不中断
- **打分完全透明**：每一分的来源（命中/未命中）逐项可查，详见 [打分规则](#打分规则v11总分-100三大模块)
- **宏观参考面板**：国内四大指数 + 纳斯达克/标普500/恒生指数参考展示（不参与个股打分），行情源异常时自动回退本地缓存快照
- **市场资讯（只聚合不解读）**：聚合公开财经快讯并按关键词归入「国内资讯 / 海外资讯 / 宏观资讯」三类，列表卡片展示（标签 · 标题 · 来源 · 时间 · 原文链接）；抓取失败时展示「资讯暂不可用」占位，不影响主表格
- **中英双语界面**：右上角「中 / EN」一键切换，无刷新、不改动数据层；界面文案走独立语言包（`app/static/i18n.js`），行业采用申万一级行业标准英文译名、指数采用市场通用英文名称，MACD / KDJ / PE / 换手率等专业指标沿用国际通用写法；股票名称与代码保持原样；语言偏好写入 `localStorage`，刷新后保持
- **历史回测模块**：用本地 3 年前复权日线对打分体系做**事后统计**——按综合匹配分分为高（≥60）/ 中（30–59）/ 低（<30）三组，分别统计持仓 5 / 10 / 20 日的上涨占比、平均收益、相对沪深300 超额、最大回撤与盈亏比，并绘制累计收益对比曲线；**全部指标均为滚动窗口计算，严格规避未来函数**（观察日 T 收盘后打分 → T+1 开盘价入场 → T+n 收盘价出场）
- **研究简报自动生成**：一键生成本地研究简报（九节：研究摘要 / 研究方法与规则 / 历史回测结论 / 分行业回测 / 多周期共振策略 / 当日候选池分析 / 研究结论与展望 / 研究局限性与风险提示 / 合规声明），内嵌分组柱状图、累计收益曲线、行业分布图与分行业横向条形图，支持导出 PDF；数据全部取自看板实时扫描与回测结果，结论可复现
- **分行业回测（v1.7.0）**：把已有回测明细按**申万一级行业**维度二次聚合，逐一给出 31 个行业中高 / 中 / 低匹配分组在 5 / 10 / 20 日周期的上涨胜率、平均收益率与最大回撤；提供行业下拉选择、全行业高匹配分组的收益条形图、靠前 / 靠后行业对照，并支持导出分行业明细 CSV。各行业样本合并回去与整体口径**逐值一致**，可对账
- **统计显著性检验（v1.7.0）**：对高匹配分组与低匹配分组在 5 / 10 / 20 日周期的收益差做 **Welch 独立样本 t 检验**（不假设方差齐性），输出均值差异、t 值、自由度、双尾 p 值与 95% 置信区间；另按自然年拆分做**分年度稳健性检验**，逐年检查结论方向是否一致。t 分布分位与 p 值由 numpy + 标准库自研实现（Lentz 连分式求正则化不完全贝塔函数），与参考值逐位对齐，不引入 scipy 依赖
- **参数敏感性分析（v1.7.0）**：对 3 组核心参数（MACD 参数、量能放大倍数、近 40 日振幅阈值）各构造 2 档扰动，每档**只改动一个参数族**、其余保持基准，分别跑全量回测与基准对照，输出分组收益变动（百分点）与「高低分组方向是否保持」，用于说明结论对参数扰动的稳健程度
- **多周期共振策略（v1.7.0）**：新增**周线级别**形态打分（MACD(3,6,3) 金叉且红柱 > 0、KDJ(9,3,3) 金叉且 J < 100，与日线规则同源），构造「日线 + 周线双共振」分组并与原单日线策略横向对比收益、胜率与回撤；周线「已收盘」由**市场交易日历**（基准指数日线）判定，而非个股自身最后成交日，从而避免停牌股把未定型周线误判为可用而引入未来函数
- **顶部标签页导航（v1.8.0）**：整站由单页长滚动改为顶部固定导航 + 五个标签页（候选池选股 / 策略回测 / 研究简报 / 市场概览 / 规则设置），切换**前端无刷新、零接口请求**，默认进入候选池页；支持 hash 直链（`#pool` / `#backtest` / …）与浏览器前进后退；窄屏（≤900px）自动折叠为汉堡菜单；中英双语切换后停留在当前页
- **研究简报在线预览（v1.8.0）**：简报页内置在线预览区，按需惰性加载当前批次的简报 HTML，可一键刷新预览或导出 PDF，无需先下载
- **打分权重可视化配置（v1.9.0）**：规则设置页为三大打分模块共 13 个细分项各提供一条**分值滑块**（核心形态 0–50 / 筹码与基本面 0–20 / 行业与板块 0–30），顶部实时显示当前配置总分与模块上限、偏离参考 100 分时给出提示。拖动滑块后**在前端用新权重重算全体候选股的匹配分**，候选池分数、排序、统计分档与个股明细同屏联动，全程**零接口请求、零后端改动**；底部「恢复默认权重」一键回到后端原始口径。调整仅作用于当前浏览器会话的展示，刷新即回默认，不影响历史回测与研究简报口径
- **研究看板**：克制的 Apple 风格应用（浅灰白底、低饱和蓝强调色、柔和涨跌色），本地打包 ECharts（离线可用），K 线 / 均线 / 成交量 / MACD / KDJ 四区联动
- **结果导出**：候选池一键导出 CSV（UTF-8 BOM，Excel 直接打开不乱码）；回测明细可按周期导出 CSV；研究简报可导出 PDF
- **REST API**：全部功能均有对应接口，自带交互式文档（`/docs`）
- **测试覆盖**：指标计算与手工递推逐值对照、规则边界用例、端到端管线、接口测试

## 页面结构（v1.8.0）

整站为**单页应用 + 顶部标签页**结构：所有面板常驻同一份 HTML，切换只做显示 / 隐藏，
**不重新加载页面、不产生任何接口请求**（数据仍按原来的时机加载与缓存）。

| 标签页 | hash | 归属内容 |
|--------|------|----------|
| 候选池选股（默认） | `#pool` | 统计概览卡、候选池主表格（筛选 / 搜索 / 排序 / 分页）、个股明细抽屉 |
| 策略回测 | `#backtest` | 分档绩效与累计收益曲线、分行业回测、统计显著性与分年度稳健性、参数敏感性、多周期共振 |
| 研究简报 | `#report` | 九节目录与元信息、**在线预览区**、导出 PDF |
| 市场概览 | `#market` | 宏观参考面板（国内 4 指数 + 海外港股 3 指数）、候选池行业分布、市场资讯 |
| 规则设置 | `#settings` | **打分权重可视化配置（v1.9.0）**：三大模块 13 条分值滑块、总分实时校验、恢复默认；其余配置项（分组阈值 / 热点行业名单 / 基础过滤条件）仍为现行口径说明 |

设计要点：

- **全局扫描面板**不归属任何标签页，始终位于页首，任何页都可直接发起扫描与导出
- **hash 直链与历史记录**：切换标签写入 `history.pushState`，支持 `#backtest` 之类直接访问与浏览器前进 / 后退；非法 hash 回落到默认页
- **图表按需重绘**：切到含图表的页面时才重绘（`redrawTabCharts`），并在下一帧统一 `resize`；隐藏面板（`clientWidth` 为 0）会被跳过，避免把画布压成 0 宽
- **简报预览惰性加载**：首次进入简报页才加载预览，且与当前扫描批次联动，切换批次后自动刷新（预览地址带时间戳绕开浏览器缓存）
- **窄屏折叠**：`≤900px` 隐藏标签栏、显示汉堡菜单（内联 SVG 图标），菜单项与标签同源，选中后自动收起
- **双语兼容**：语言切换只重绘当前页，标签文案与新增区块文案均纳入语言包，切换后停留在原标签页

改造前后纵向长度对比（本机 1440×900，候选池 200 行 / 页）：

| 标签页 | 面板高度 |
|--------|----------|
| 候选池选股 | 11520px（其中表格本身约 11200px，属分页前的正常长度） |
| 策略回测 | 3674px |
| 研究简报 | 952px |
| 市场概览 | 5007px |

WMI 不可用时回退到 `DETACHED_PROCESS | CREATE_NEW_PROCESS_GROUP`。
日志写入 `output/uvicorn.log`，实际的服务入口是 `scripts/serve_local.py`
（由它自行处理日志重定向，可单独运行）。

> **为什么回测满分是 81 分而不是 100 分？**

> （`BT_SCORE_MAX = 81`），分组阈值仍沿用 60 / 30。这一取舍已在简报的「研究局限性」中明示。

## 打分规则（v1.1，总分 100，三大模块）

> 计算口径：MACD(3,6,3)、KDJ(9,3,3)、价格采用前复权。所有参数集中于 `app/config.py`。
> 规则完整说明另见 [docs/project_report.md](docs/project_report.md)。

### 第一步：基础过滤（不满足直接剔除，不计分）

| # | 规则 | 说明 |
|---|------|------|
| 1 | 剔除 ST、*ST、退市整理股票 | 按证券简称关键词识别 |
| 2 | 上市天数 ≥ 365 天 | 沪深交易所上市日期接口，失败时按本地 K 线窗口估计 |
| 3 | 当日非停牌 | 当日成交额 > 0 |
| 4 | 剔除北交所股票 | 仅保留 60/68/00/30 开头 |

### 第二步：核心形态匹配分（0–50 分）

| # | 条件 | 分值 |
|---|------|------|
| 1 | MACD(3,6,3) 金叉且红柱大于 0（DIF > DEA 且 MACD柱 > 0） | +15 |
| 2 | KDJ(9,3,3) 金叉且 J 值小于 100（K > D 且 J < 100） | +12 |
| 3 | 量能达标：当日成交量 > 1.3 × 近5日均量 | +8 |
|   | 量能翻倍：当日成交量 > 2 × 近5日均量（与上项叠加） | +5（量能满分 13） |
| 4 | 换手率健康度：当日换手率处于 [3%, 15%] 区间 | +5 |
| 5 | 前期横盘：近40个交易日最高价/最低价 ≤ 1.8 | +5 |

### 第三步：筹码与基本面加分（0–20 分）

| # | 条件 | 分值 |
|---|------|------|
| 1 | 筹码集中度 ≤ 18% | +3 |
|   | 筹码集中度 > 20%（在 3 分基础上再加 5 分，满分 8；缺失计 0 分） | 至 8 |
| 2 | PE 行业分位：低于所属行业 30% 分位 +6；30%-70% 分位 +3；高于 70% 或缺失 0 | 0–6 |
| 3 | 5日涨幅健康度：近5日涨幅处于 [5%, 20%] 区间 | +6 |

> PE 行业分位口径：免费接口无行业 3 年历史 PE 序列，采用同行业当日截面分位近似
> （行业有效样本 < 5 时计 0 分）；PE 为市盈率 TTM。

### 第四步：行业与板块加分（0–30 分）

| # | 条件 | 分值 |
|---|------|------|
| 1 | 板块属性：创业板（30 开头）/ 科创板（68 开头） | +8 |
| 2 | 热点行业加成：所属行业命中热点名单（可编辑 `config/hot_industries.json`，保存后下次扫描/重算自动生效） | +22 |

**综合匹配分 = 核心形态分（0–50）+ 筹码基本面分（0–20）+ 行业板块分（0–30），范围 0–100 分。**

### 宏观参考面板（仅展示，不参与个股打分）

- 国内：上证指数、深证成指、创业板指、科创50
- 海外/港股参考：纳斯达克、标普500（隔夜）、恒生指数（当日）
- 行情源不可用时自动回退最近一次成功快照（本地缓存），并标注数据时间。

### 附加展示字段（仅展示，不参与打分，不做任何判断）

| 字段 | 说明 |
|------|------|
| MACD红柱相对前高收缩 | 布尔值。定义为：当日红柱 > 0 且回看窗口（不含当日）内柱最大值 > 0 且当日柱 < 前高。**历史见顶相关指标，仅供研究** |
| KDJ-J 值 | 当日 J 值 |
| 筹码集中度 | 最近交易日 90 日成本集中度 |
| 当日换手率 | 来自行情快照 |
| PE(TTM) | 市盈率 TTM（腾讯行情） |
| 近5日涨幅 | 最新收盘 / 5个交易日前收盘 − 1 |

### 分数含义

综合匹配分表示**当前个股与历史上升段启动样本的特征相似程度**：

- 分数高 = 当前形态与历史样本的启动前特征相似度高
- 分数**不表示**未来上涨概率，不构成任何操作指引
- **历史数据不等于未来表现**

## 市场资讯模块

市场概览页的「市场资讯」只做**聚合与归类**：内容为第三方公开财经快讯的原文标题与链接，
本工具不生成、不评论、不解读任何资讯，也不参与个股打分。

### 三个分类口径

| 分类 | 涵盖内容 | 判定关键词（节选） |
|------|----------|--------------------|
| 国内资讯 | A 股动态、上市公司公告、行业政策、流动性相关 | A股、沪指、上市公司、减持、回购、公告、龙虎榜… |
| 海外资讯 | 美股、纳斯达克、标普 500、美联储、港股、中概股、海外公司与地缘 | 美股、纳斯达克、美联储、恒生、中概股、海外国别与公司名… |
| 宏观资讯 | 经济数据、货币与财政政策、大宗商品定价 | 央行、社融、CPI、PPI、PMI、LPR、统计局、WTI、布伦特… |

判定顺序为「境内市场强特征 → 海外 → 宏观 → 国内兜底」，因此
「美联储加息落地 A 股三大指数集体高开」这类跨域标题会归入国内资讯。
分类为**关键词启发式**，仅用于辅助浏览，不保证逐条准确。

### 数据源与降级

依次尝试东方财富全球快讯 → 同花顺 → 财联社 → 富途牛牛 → 新浪财经，
任一源可用即采用，多源结果按标题指纹去重；结果写入本地缓存（默认 30 分钟）。
**全部源失败时接口返回 `available=false` 与「资讯暂不可用」**，
前端展示占位提示，不影响候选池、筛选、导出等主功能。

### 中性化过滤

为保持本项目的措辞规范，标题含交易指令类表述的资讯条目会被整条跳过
（词表见 `app/config.py` 的 `NEWS_BLOCK_PARTS`，以片段拆分存储）。
如需完整保留第三方原文，将该元组清空即可。

> 资讯为第三方公开内容，不代表本工具观点，不构成任何形式的操作指引。

### 研究分析的统计口径（v1.7.0）

- **二次聚合、不重算指标**：分行业回测、显著性检验、参数敏感性中的分行业与分组绩效，
  全部由已有 `bt_trades` 明细二次聚合得到，与回测主口径**同源**，可逐值对账。
- **占位行业不计入行业统计**：未能匹配到申万一级行业的个股在回测明细中记为 `其他`，
  它不是行业分类体系的一员，已在分行业聚合与行业全集中统一排除，
  保证「覆盖行业数 ≤ 行业总数」。
- **t 检验的参数选择**：两个分组的样本量与方差均不相等，故采用 Welch 检验而非等方差 t 检验；
  显著性水平 `SIG_ALPHA=0.05`。p 值按有效数字展示，极小值显示为「< 1e-12」，
  不以固定小数位四舍五入（否则 1e-21 量级会被显示成 0）。
- **不依赖 scipy**：正则化不完全贝塔函数用 Lentz 连分式实现，临界值用二分法求解，
  运行时依赖保持 `fastapi / uvicorn / akshare / pandas` 四项不变。
- **敏感性变体为单因子扰动**：每个变体只在一个参数族内改动（MACD 三要素视为同一族），
  其余参数保持基准，避免多因子同时变动导致无法归因。
- **共振分组的周线可用性**：周线「已收盘」以基准指数日线的市场周最后交易日为准；
  个股停牌不会让未定型周线提前可用。周线数据不足 `WEEKLY_MIN_BARS` 的个股标记为不共振。

### 回测与简报的相关约定

- **口径可复现**：回测区间、调仓步长、持仓周期、分组阈值全部集中在 `app/config.py`（`BT_*`），
  且回测数据存放在**独立的 `bt_klines` / `bt_index` 表**，与看板扫描用的 `klines` 物理隔离，
  互不影响。
- **前瞻偏差（未来函数）防御**：全部技术指标以滚动窗口预计算，第 i 个交易日只依赖第 i 日及之前的数据；
  观察日 T 收盘后打分，入场取 **T+1 开盘价**、出场取 **T+n 收盘价**；测试中通过「截断未来数据后
  前段逐格结果一致」与反向验证双重锁定。
- **可复现满分 81 分**：筹码集中度、PE 行业分位、换手率三项在历史时点无免费可复现数据源，
  回测口径下统一计 0 分（`BT_SCORE_MAX=81`），因此回测分组阈值仍沿用 60 / 30。
- **剔除规则与看板一致**：剔除 ST / *ST / 退市整理、上市不满 365 天、停牌个股与北交所股票。
- **样本独立性**：每 20 个交易日设一个调仓点，5 / 10 / 20 日三个持仓周期的样本互不重叠。

## 技术实现要点

- **增量更新策略**：已有缓存的个股，当日 K 线由行情快照直接构造追加（避免逐股历史请求）；快照「昨收」与缓存最近收盘价的相对误差超过 0.1% 时（多为除权除息导致的前复权价跳变），自动全量重拉该股，保证全市场前复权口径一致
- **线程模型**：SQLite 连接仅在主线程读写；网络请求（历史K线、筹码）在线程池并发执行，结果统一回主线程落库，规避 SQLite 并发写问题
- **容错降级**：任一数据接口失败仅影响对应个股或对应字段（如筹码缺失计 0 分），单点失败不扩散、不中断整体扫描
- **参数集中**：全部指标参数、过滤阈值、分值、缓存时效集中于 `app/config.py`，修改口径无需触碰业务代码

## 数据来源与口径

- 行情数据：[AKShare](https://github.com/akfamily/akshare) 免费公开接口（东方财富等公开数据源），仅用于个人研究，请遵守数据源方的使用条款
- 价格口径：前复权
- 指标口径：MACD(3,6,3)，红绿柱 = 2 × (DIF − DEA)；KDJ(9,3,3)，SMA 采用通达信递推口径
- 筹码集中度：90 日成本集中度（`stock_cyq_em`），可选数据
- 市场资讯：东方财富 / 同花顺 / 财联社 / 富途牛牛 / 新浪财经的公开快讯接口（依次降级），仅展示第三方原文标题与链接
- 回测基准：沪深 300 指数（`sh000300`）日线，与个股同样采用前复权口径下的收盘价序列
- 回测区间：默认近 3 年（约 2023-12 起），调仓步长 20 个交易日，持仓周期 5 / 10 / 20 日

### 数据使用边界（发布说明）

- **不使用任何付费或需授权的数据源。** 本项目不涉及 Wind、Tushare、聚宽、米筐等任何商业数据服务，代码中**不存在**付费数据源的接口调用与密钥配置。
- **仓库内不含任何完整原始行情数据。** `data/`（本地数据库）、`output/`（导出与日志）均已在 `.gitignore` 中排除；本仓库只保留**规则、公式、代码与文档**，行情数据由使用者在本地自行拉取。
- **示例数据**：仅测试代码中使用少量构造数据验证计算逻辑，为公开可复现的合成样本，不含任何来自付费数据源的数据。
- **密钥管理**：本项目运行不需要任何密钥。仓库只提供不含密钥的模板文件 [`.env.example`](.env.example)；若你自行接入需要密钥的数据源，请写入 `.env`（已被忽略，不会入库）。
- **资讯模块**仅展示第三方公开快照的标题、来源与链接，不转载正文内容。
