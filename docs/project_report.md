# 项目技术报告 —— A股历史形态匹配研究看板

> 本工具仅对 A 股历史公开数据做统计研究：输出为形态特征匹配度分数，表示当前个股与
> 历史上升段启动样本的特征相似程度，不代表未来表现，不构成任何形式的操作指引。
> **历史数据不等于未来表现，市场有风险，研究需谨慎。** 仅限本地运行，请勿部署到公网。

## v1.1 规则详解（总分 100）

### 一、基础过滤（不满足直接剔除，不计分，与 v1.0 保持一致）

| 序号 | 规则 | 参数 |
|------|------|------|
| 1 | 剔除 ST / *ST / 退市整理股票 | 名称关键词 `ST`、`*ST`、`退` |
| 2 | 上市天数不足 | `< 365` 自然日剔除 |
| 3 | 停牌 / 无成交 | 当日成交额 `<= 0` 剔除 |
| 4 | 剔除北交所 | 仅保留 60 / 68 / 00 / 30 代码前缀 |

### 二、模块一：核心形态匹配分（0-50）

| 序号 | 指标 | 条件 | 分值 |
|------|------|------|------|
| 1 | MACD(3,6,3) | 金叉（DIF > DEA）且红柱 > 0 | 15 |
| 2 | KDJ(9,3,3) | 金叉（K > D）且 J < 100 | 12 |
| 3 | 量能达标 | 成交量 > 1.3 × 近5日均量 | 8 |
|    |          | 成交量 > 2 × 近5日均量（叠加） | +5（量能满分 13） |
| 4 | 换手率健康度 | 当日换手率 ∈ [3%, 15%] | 5 |
| 5 | 横盘形态 | 近40个交易日 最高价/最低价 ≤ 1.8 | 5 |

技术指标口径：MACD 红绿柱 = 2 × (DIF − DEA)；KDJ 采用通达信 SMA 平滑口径；
价格为前复权。

### 三、模块二：筹码与基本面加分（0-20）

| 序号 | 指标 | 条件 | 分值 |
|------|------|------|------|
| 1 | 筹码集中度 | ≤ 18% | 3 |
|   |            | > 20%（在 3 分基础上再加 5 分） | 至满分 8 |
|   |            | 介于 18%-20% / 数据缺失 | 0 |
| 2 | PE 行业分位 | 低于所属行业 30% 分位 | 6 |
|   |             | 行业 30%-70% 分位 | 3 |
|   |             | 高于 70% 分位 / 缺失 | 0 |
| 3 | 5日涨幅健康度 | 近5日涨幅 ∈ [5%, 20%] | 6 |
|   |               | 区间外 / 缺失 | 0 |

**PE 行业分位数据口径**：免费公开接口无「行业 3 年历史 PE 序列」，
当前采用**同行业当日截面分位**近似（同一行业分类下全部有效 PE>0 的个股
参与排序；行业内有效样本数 < 5 时该项计 0 分，参数
`config.PE_MIN_INDUSTRY_PEERS`）。PE 为市盈率 TTM（腾讯行情），
亏损股（PE ≤ 0）不参与分位计算。

**筹码集中度**来自东财筹码接口（可选抓取）；本机网络不可达时该项计 0 分，
不影响其他项（设计内降级）。

### 四、模块三：行业与板块加分（0-30）

| 序号 | 指标 | 条件 | 分值 |
|------|------|------|------|
| 1 | 板块属性 | 创业板(30) / 科创板(68) | 8 |
|   |          | 沪主板 / 深主板 | 0 |
| 2 | 热点行业加成 | 所属行业命中热点名单 | 22 |
|   |              | 未命中 | 0 |

**热点行业名单**：`config/hot_industries.json`，可自由编辑，保存后下次
扫描或重算自动生效（无需重启服务）。行业名支持前缀匹配，例如
`半导体` 可命中以 `半导体` 开头的行业名称。

### 五、附加展示字段（仅展示，不参与打分）

- **MACD 红柱相对前高收缩**：当日红柱 > 0、回看 20 个交易日（不含当日）
  红柱最大值 > 0、且当日红柱 < 前高。为历史见顶相关指标，仅供研究。
- KDJ-J 值、当日换手率、近40日最高/最低价、PE(TTM)、近5日涨幅等。

### 六、宏观参考面板（仅展示，不参与个股打分）

- 国内：上证指数、深证成指、创业板指、科创50
- 海外/港股参考：纳斯达克、标普500（隔夜）、恒生指数（当日）
- 行情源不可用时自动回退最近一次成功快照（本地缓存），并标注数据时间。

## 数据源与降级策略

| 数据 | 主源 | 备源 | 降级行为 |
|------|------|------|----------|
| 全市场快照 | 东财 | 新浪分页列表 | 部分页失败时使用已获取部分 |
| 日K（前复权） | 东财（熔断保护） | 腾讯 fqkline（多镜像） | 逐股失败跳过 |
| 行业分类 | 申万一级行业成分（31 个） | 东财行业板块 → 新浪行业板块 → 北交所证监会行业 | 依次补缺，经别名归一化后仍无法归类的丢弃 |
| PE(TTM) | 腾讯批量行情 | — | 失败时分位项计 0 分 |
| 筹码集中度 | 东财 | — | 失败计 0 分 |
| 国内指数 | 东财（首个分组失败即熔断） | 腾讯 | 失败回退本地缓存快照 |
| 海外/港股指数 | 腾讯 | — | 失败回退本地缓存快照 |
| 市场资讯 | 东财全球快讯 | 同花顺 → 财联社 → 富途牛牛 → 新浪财经 | 单源超时/失败切换下一源；全部失败返回 `available=false` |

### 行情源的「无成交额」陷阱（重要）

腾讯 fqkline 返回的日 K **不含成交额**。若全量刷新时用腾讯源重建了当日 K 线，
`amount` 字段会为空，而基础过滤第 3 条（当日成交额 > 0，用于剔除停牌）会因此
把大量正常个股判为停牌剔除——本项目实测曾出现候选池从 4870 只骤降到 848 只。

修复分两处：

1. `sync_spot_day()` 取代原 `append_spot_if_missing()`：当日 K 线已存在时不再直接跳过，
   而是**回填 `amount` / `turnover_rate` 空字段**；
2. `compute_stock()` 增加快照成交额兜底——K 线成交额为空时改用行情快照的成交额判定。

## 离线重算说明

K 线缓存保留时，可仅重算分数而不重新拉取行情：

```bash
python scripts/rescore_v11.py
```

适用于修改热点行业名单或调整打分参数后快速刷新候选池。
重算时换手率取自 K 线缓存最后一天；PE 为当前实时值。

### 设计令牌（app.css 顶部集中定义）

| 类别 | 取值 |
|------|------|
| 背景 / 卡片 | `--bg #f6f7f9`（极浅蓝灰）、`--card #ffffff`、`--card-soft #fcfcfd`（微冷白） |
| 文字 | `--text #1c1f24`（深石墨黑）、`--text-2 #454b55`、`--muted #78818d`、`--faint #a4adb9` |
| 强调色 | `--accent #3b6fd4`（低饱和蓝）、`--accent-soft #eef3fc`、`--accent-line #dbe5f6` |
| 涨跌 | `--up #c4574e`（柔和红）、`--down #3f9c78`（柔和绿）——遵循 A 股涨红跌绿惯例 |
| 圆角 | `--radius-lg 16px` / `--radius 12px` / `--radius-sm 9px` / `--radius-pill 999px` |
| 阴影 | `--shadow` 为「1px + 2px 极轻投影」，不使用厚重阴影 |
| 字号 | `--fs-h1 17` / `--fs-h2 15` / `--fs-h3 13.5` / `--fs-body 13` / `--fs-small 12` / `--fs-micro 11`；数字 `--fs-metric 30`、`--fs-macro 23` |

**视觉层级原则**：标题用 600 字重（比数字轻），关键数字用 700 字重 + 负字距，
说明文字用 `--faint` 小字；全页只使用语义变量，不出现魔法色值。

### 表格与标签

- 13 列用 `<colgroup>` 固定百分比列宽，`table-layout: fixed` 保证列宽稳定；
  中英各一套百分比（`POOL_COLS`，两套之和均为 100），英文名更长时列宽自动重分配
- `thead th { position: sticky; top: var(--sticky-top) }`，`--sticky-top` 由脚本按顶部导航
  实际高度写入（`syncStickyOffset()`），导航换行时不会错位
- **不使用斑马纹**，靠极浅分隔线（`--border-soft`）与悬停底色区分行
- 12 个指标命中标签固定宽度、`border-radius: 999px` 胶囊形，按 6 个/行换行成 2 行与行高对齐；
  命中为浅蓝（`--accent-soft` + `--accent`），未命中置灰。
  中文标签 42px、英文标签 45px（拉丁字母更宽），英文标签文案控制在 5 字符内以维持 2 行布局
- 板块 / 行业列在英文下允许折行并降至 10.5px，避免市场标准英文名被省略号截断

### 个股明细抽屉的渲染约束（重要）

明细图采用 ECharts **多 grid 布局**（K 线 / 成交量 / MACD / KDJ 四个绘图区）。
在该布局下，`xAxis` 与 `yAxis` 必须**同时显式声明 `gridIndex`**：

```js
xAxis: [0, 1, 2, 3].map((i) => ({ type: "category", data: dates, gridIndex: i })),
yAxis: [0, 1, 2, 3].map((i) => ({ scale: true, gridIndex: i })),
```

若仅 `yAxis` 指定而 `xAxis` 缺省，ECharts 会把全部 x 轴挂到 0 号 grid，
其余 grid 出现「有 y 轴无 x 轴」的错配，渲染期抛出
`Cannot read properties of undefined (reading 'type')`。
该异常发生在 `setOption` 内部，会被外层 `try/catch` 捕获，
前端只表现为一句「明细数据加载失败」，排查时容易误判为接口问题。

> 排查经验：接口返回 200 且字段完整、浏览器无未捕获异常时，
> 应怀疑渲染层异常被 `try/catch` 吞掉——可在控制台手动调用渲染函数并打印 `e.stack` 定位。

### 详情接口返回结构

`GET /api/pool/{code}?days=120` 同时返回三类内容：

| 字段 | 说明 |
|------|------|
| `dates` / `kline` / `indicators` | 前复权日 K 与 MACD、KDJ、MA5/10/20/60 序列 |
| `profile` | 代码、名称、板块、行业（申万一级） |
| `score` | 综合匹配分、三模块得分与逐项命中明细（`breakdown` / `metrics` / `display`） |

档案与得分随详情一并返回，抽屉展示不依赖列表页缓存，口径始终一致。

### 缓存控制

首页返回 `Cache-Control: no-cache`，静态资源带版本号（`app.js?v=1.5.0`）。
两者配合可确保升级后浏览器立即加载新版脚本，避免旧版脚本产生接口路径
或字段结构不匹配导致的「功能莫名失效」。

## 市场资讯模块实现（v1.4.0）

### 定位

**只做聚合与归类**：内容为第三方公开快讯的原文标题与链接，本工具不生成、不评论、
不解读任何资讯，也不参与个股打分。前端在所有主功能渲染完成之后才异步加载资讯，
**资讯接口失败绝不阻塞候选池、筛选、导出等主功能**。

### 数据源

| 顺序 | 接口（AKShare） | 来源 | 字段 |
|------|-----------------|------|------|
| 1 | `stock_info_global_em` | 东方财富 | 标题 / 摘要 / 发布时间 / 链接（最完整，单次约 200 条） |
| 2 | `stock_info_global_ths` | 同花顺 | 标题 / 内容 / 发布时间 / 链接 |
| 3 | `stock_info_global_cls` | 财联社 | 标题（常为空）/ 内容 / 日期 + 时间（无链接，回退源主页） |
| 4 | `stock_info_global_futu` | 富途牛牛 | 标题 / 内容 / 发布时间 / 链接 |
| 5 | `stock_info_global_sina` | 新浪财经 | 时间 / 内容（无链接，回退源主页） |

抓取到目标条数（默认上限的 2 倍）即停止请求后续源；多源结果按
「标题去除非字母数字字符后取前 36 字符」的指纹去重，保留先出现（信息最完整）的一版。

### 超时保护的一个坑

单源超时不能直接写成 `with ThreadPoolExecutor(...) as pool: pool.submit(fn).result(timeout=t)`——
线程池的上下文管理器在退出时会 join 工作线程，**即使已经超时也会被卡住**，超时保护形同虚设。
本项目改用「守护线程 + `queue.Queue(maxsize=1)`」：超时后直接放弃该线程，不再等待。

### 分类规则

判定顺序：**境内市场强特征 → 海外 → 宏观 → 国内兜底**。

| 分类 | 判定要点 |
|------|----------|
| 国内资讯 | A股、沪指、深证成指、创业板指、北交所、上交所、深交所、证监会、涨停、龙虎榜、新股、解禁、两融、银行间、减持、增持、回购、中标、公告、上市公司 等 |
| 海外资讯 | 美股 / 纳指 / 标普 / 道指 / 美联储 / 港股 / 恒生 / 中概股 / 华尔街 / 美债 / 非农；海外国家与地区名、国际组织、地缘海域、海外知名公司与机构、海外地名 |
| 宏观资讯 | 央行 / 货币政策 / 社融 / CPI / PPI / PMI / GDP / LPR / MLF / 降准 / 降息 / 财政 / 国债 / 汇率 / 统计局 / 关税；以及 WTI、布伦特、LME 等大宗商品定价相关 |

两点设计取舍：

1. **境内强特征优先**：否则「美联储加息落地 A 股三大指数集体高开」会被误归为海外资讯。
2. **「中国 / 国内 / 全国」不放强特征**：它们是兜底类目，若放进强特征会抢走本应
   归入宏观资讯的央行、统计局类条目（默认兜底即为国内，无需重复声明）。

分类为**关键词启发式**，仅用于辅助浏览，不保证逐条准确，已在 README 中明示。

### 中性化过滤

为保持项目措辞规范，标题含交易指令类表述的条目整条跳过。词表存放在
`app/config.py` 的 `NEWS_BLOCK_PARTS`，与 `scripts/word_check.py` 同法，
以「前半 + 后半」片段拆分存储，避免配置文件自身被合规自检命中。
如需完整保留第三方原文，将该元组清空即可。

### 缓存与降级

抓取结果整体写入 `meta` 表的 `news_feed_cache` 键并设 30 分钟有效期；
应用启动时通过 `lifespan` 后台线程预热一次。全部源失败时接口返回：

```json
{ "available": false, "items": [], "message": "资讯暂不可用" }
```

前端渲染「资讯暂不可用」占位，模块结构保持完整，页面其余部分不受影响。

## 中英双语实现（v1.5.0）

### 设计边界

采用**基础双语方案**：只翻译界面文案，不触碰打分逻辑、数据层与接口。
具体约定：

| 对象 | 处理方式 |
|------|----------|
| 界面文案（标题 / 按钮 / 标签 / 免责声明 / 统计说明 / 筛选选项 / 弹窗文案 / 页脚） | 全部走语言包 |
| 专业指标（MACD / KDJ / PE(TTM) / 换手率） | 中英一致，沿用国际通用写法 |
| 指数名称 | 市场通用英文名（上证指数 → SSE Composite，标普500 → S&P 500 等） |
| 行业分类 | 申万一级行业标准英文译名（31 个全覆盖） |
| 股票名称 / 代码 | **不翻译**，保持原样 |
| 市场资讯标题 | **不翻译**，英文界面保留第三方中文原文并标注「News in Chinese」 |

### 词条组织

语言包集中在 `app/static/i18n.js`，对外暴露五个方法：

```js
I18N.t(key, vars)     // 取词，支持 {name} 占位符替换
I18N.industry(name)   // 行业中文名 → 当前语言展示名
I18N.board(name)      // 板块中文名 → 当前语言展示名
I18N.indexName(name)  // 指数中文名 → 当前语言展示名
I18N.setLang("en")    // 切换语言并持久化
```

两条替换路径：

1. **静态文案**：页面元素加 `data-i18n`（另有 `data-i18n-ph` / `-title` / `-aria`
   对应 placeholder、title、aria-label），`applyStatic()` 一次性批量替换；
2. **动态文案**：渲染函数一律调用 `t()` 取词，不再出现字面量文案。

### 切换流程与重绘

```js
I18N.onChange(() => { syncLangUI(); rerenderAll(); });
```

`rerenderAll()` 用**已缓存数据**重绘宏观面板、统计卡、筛选下拉、候选池表格、
行业分布图、资讯模块与明细抽屉，**不发起任何接口请求**（验收实测切换后
`performance.getEntriesByType("navigation").length` 仍为 1，即未发生页面跳转/刷新）。
语言偏好写入 `localStorage`（键 `patternlab.lang`），刷新后保持。

### 三个容易踩的坑

1. **接口参数必须保持中文**：行业、板块的 `<option value>` 始终写入接口认识的
   原始中文值，切换语言只替换展示文本。若把 value 也翻译，筛选会全部失效。
2. **图表需要显式重绘**：ECharts 的轴标签与 series 名称不会被 DOM 文案替换波及，
   必须重新 `setOption`。同时在英文下把行业图的 `grid.left` 从 110 加宽到 205，
   否则标准英文行业名（如 Petroleum & Petrochemicals）会被容器左边缘裁切。
3. **`display` 会覆盖 `[hidden]`**：`#newsLangBadge` 需要 `display: inline-block`，
   必须补一条 `.news-lang-badge[hidden] { display: none; }`，
   否则中文界面下该标注不会隐藏。
